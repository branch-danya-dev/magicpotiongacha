# Potion Tycoon: Magic Clicker

Roblox-тайкун: магическая фабрика с фамильярами, производственными цепочками и логистикой.

## Текущая версия: M1 · производство и обучение (Draft)

Это **серый прототип, не готовый публичный релиз**. Включены:

- Восемь отдельных участков, фиксированные рабочие места, покупка улучшений кнопками на полу.
- Кликер эссенции; отдельный рабочий у кристалла и пассивные улучшения.
- Грядка, угольная шахта, дистиллятор, котёл, склад и перевозчик.
- Три фиксированных стартовых фамильяра и гарантированный наём дополнительных рабочих за Gold.
- Один питомец на одно рабочее место; эффективность ограничена уровнем станции, исходные статы сохраняются.
- Рецепты Healing, Fire Extract, Rage: реальные ингредиенты, резервирование партии, полуфабрикаты, автоматизация после первой ручной варки.
- Ручная заправка Essence в бак котла; трубы за 28 Gold доставляют Essence и жидкие полуфабрикаты. Перевозчик доставляет твёрдое сырьё и квестовые ящики.
- Автоматическая продажа обычных зелий; три предложения NPC, один активный заказ; ящики учитываются отдельно у котла, в пути и на квестовом складе.
- Одинаковая онлайн/офлайн-симуляция, лимит офлайна 7200 секунд, сохранённое состояние случайных производственных событий.
- Серверная проверка запросов, частоты, участка и расстояния; session-locked сохранение с отказом от записи при ошибках.
- Сохраняемое пошаговое обучение, серверные причины простоя, прогресс партий, грузы и дедлайны; меню по умолчанию закрыто, кнопки доступны для touch.
- Миграция старых M0-профилей без повторной выдачи работников, сброса валюты или удаления оплаченных партий.

**Не включены:** гача, случайные статы новых покупок, Fuse, обмены, Rebirth, три художественные эпохи, Robux-покупки, финальная графика. Эти системы остаются в [плане](docs/ROADMAP.md).

## Быстрый запуск на Windows

Нужны Git, Node.js 22+ (с npm), Roblox Studio и встроенный `tar.exe` из Windows 10/11. Команды в PowerShell:

```powershell
git clone https://github.com/branch-danya-dev/magicpotiongacha.git
cd magicpotiongacha
git switch feat/m1-production-onboarding
npm run tools
npm test
```

Установка не требует `npm install`: JavaScript-скрипты используют только стандартную библиотеку Node.js. Luau 0.745 и Rojo 7.7.1 скачиваются с официальных GitHub Releases, SHA-256 проверяются по `tools.lock.json`.

После проверки открыть **`build/PotionTycoon.rbxlx`** в Roblox Studio и нажать Play. Rojo-плагин для этого не нужен. Тот же файл доступен в артефактах успешного GitHub Actions run. Для дальнейшей разработки с live sync установить Rojo-плагин соответствующей версии и выполнить `npm run serve`.

Скрипты установки также поддерживают x64 Linux и macOS. Для Linux/Windows ARM использовать подходящие инструменты через Rokit вручную.

## Как пройти первый цикл

1. Подойти к кристаллу, собрать эссенцию через prompt или кнопку в меню.
2. У грядки собрать две Мандрагоры вручную. Либо назначить сову-фермера и забрать её урожай.
3. Назначить сову на грядку, слайма на логистику, кота на котёл. У котла выбрать Healing → «Загрузить ингредиенты и Essence» → сварить партию вручную. Обычное зелье сразу принесёт 14 Gold.
4. Накопить 28 Gold и купить трубы на складе. Они заправляют баки котлов; без труб бесплатная ручная загрузка остаётся доступна. После первой ручной Healing можно включить автоварку.
5. Накопить 140 Gold и улучшить кристалл для пассивной Essence: у жёлтой площадки удержать F / кнопку покупки на экране либо нажать «Улучшить» в меню. До покупки кликать по кристаллу или варить вручную. Простое касание площадки не тратит Gold. С работающими трубами, грядкой, перевозчиком и котлом фабрика теперь работает без кликов.
6. У доски заказов принять контракт, дождаться **доставки** нужных ящиков и явно сдать его. Ящики у котла и в пути ещё не считаются доставленными. Излишки продаются автоматически. При истечении срока все готовые ящики продаются один раз по обычной цене; бонус не начисляется.
7. Купить шахту и дистиллятор, улучшить котёл. На складе нанять дополнительных фиксированных рабочих. Вручную впервые приготовить Fire Extract и Rage, затем включить их автоматизацию.

Меню открывается кнопкой «Фабрика» или prompt у станции. Действия требуют находиться рядом с нужным объектом своего участка. Назначение: объект → «Назначить фамильяра» → свободный рабочий. Чтобы переназначить занятого питомца, сначала снять его с предыдущего места.

Кнопка текущего шага открывает подсказку у нужного объекта. Уже выполненные шаги сохраняются, даже если выполнены не по порядку. При заполнении склада можно подтвердить утилизацию ненужного сырья. Снятый перевозчик оставляет груз в пути до нового назначения.

## Сохранение: важное различие режимов

По умолчанию **Studio использует память процесса** (`UseMemoryInStudio = true`). Явная отметка в HUD сообщает, что после Stop прогресс не сохраняется. Это явный режим, а не резервный вариант после ошибки DataStore.

Для теста настоящего сохранения:

1. Создать **отдельный приватный QA experience**, не подключённый к данным живой игры.
2. Установить `UseMemoryInStudio = false` в `src/server/ServerSettings.luau` и пересобрать.
3. Только у этого QA experience включить Studio Access to API Services или запускать опубликованную приватную версию через клиент Roblox.
4. Пройти [ручную приёмку](docs/ACCEPTANCE.md). Сохранения M0 используют отдельное имя `PotionTycoon_M0_dev_v1`.

Не открывайте Studio-доступ к боевым данным. При ошибке загрузки, неизвестной версии профиля или занятой сессии игра **не подменяет прогресс пустым профилем**.

## Проверки

```powershell
npm test
```

Команда компилирует все Luau-файлы, анализирует переносимые модули, запускает настоящие Luau-тесты и собирает place через Rojo. CI повторяет это на Ubuntu и Windows. Компиляция и fake DataStore-тесты **не заменяют запуск Roblox Studio, реальный DataStore и мобильную приёмку**.

`build/verification.log` содержит исходный SHA, результаты и три строки `ECONOMY` с воспроизводимыми сценариями. CI прикладывает этот лог вместе с place и sourcemap.
