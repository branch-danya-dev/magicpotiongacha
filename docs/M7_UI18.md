WorldContext is the sole gameplay label/prompt presentation owner, independent of
the environment quality and release-art flag. EnvironmentView yields annotation
writes while that owner is active. Lighting/weather/VFX behavior remains unchanged.
World callbacks, ownership, range checks, prices, holds and request IDs stay on the
server; client visibility never grants authority. CoreGui is not disabled.

Eligible prompts require the local owner or the public trade post, native activation
distance, a live character, camera bounds and an unobstructed camera ray. Stable
sorting and hysteresis select one; X / RB / the touch button cycle neighbours.
Only the chosen native prompt is enabled, preserving Roblox's keyboard/gamepad/
touch and hold control. Opening a panel or Roblox menu suppresses world prompts.

Panels use CoreUISafeInsets. Portrait has a bottom sheet; desktop/landscape use
a compact side panel. The nearby action rail leaves room for touch locomotion.
Closing keeps server state, selected page and scroll position. The local memory
warning moves into the requested quality/settings page, not the ordinary HUD.
