## 2. Как устроена текущая версия

```text
src/                         Исторический M0–M6 + V8 / общая база, НЕ конечный V1 place
qa/alchemy/                  V1-01 extractor/passive policy + временные визуалы
qa/garden/                   V1-02 CropCatalog + GardenV1 simulation + tests
qa/alchemy_v1/               V1-03 RecipeCatalog + AlchemyV1 + PotionBook UI + tests
qa/stability/                P0 без compulsory pet, collision proxies, stable forest LOD
qa/forest/                   R3 forest geometry / LOD / cloud occlusion
qa/lunar/                    Три Луны и ночной цикл
qa/sky-landmark/             R3 World Tree / фоновое облачное море
scripts/build-forest.mjs     Компонует лесной island candidate
scripts/build-alchemy-first.mjs
                             ГЕНЕРАТОР ТЕКУЩЕЙ ИГРЫ: extractor + garden + alchemy + P0
scripts/apply-v1-garden*.mjs, apply-v1-alchemy.mjs, apply-v1-stability.mjs
                             Слои для Rojo place
default.project.json         Старый/базовый place, НЕ текущая V1-03
build/                       Временно создаётся npm test и билдерами, в Git не хранится
```

Системы V1-01→V1-03 существуют **наследуемой цепочкой**, а не как независимые бинарные патчи к файлу владельца. Для новой сборки использовать исходный репозиторий и `scripts/build-alchemy-first.mjs`. Любой `.rbxlx`, созданный руками вне этой цепочки и не имеющий HEAD/owner/SHA256 receipt, не считается воспроизводимым кандидатом.

## 3. Механики — согласованное минимальное ядро

**Essence:** экстрактор производит Essence пассивно; уровень 1 — 1/сек, следующие 2 / 6 / 18 / 48. Логический ID источника сохраняется `crystal` для совместимости. Ручной клик для новых V1-профилей запрещён сервером.

**Фамильяры:** их статы и коллекция остаются в прежнем профиле, но в V1 QA они не производят сырьё и не дают бонусов. Выбор стартового фамильяра **не обязателен** и не запускает полноэкранное окно. Не удалять объекты и сохранённые данные. Питомцы могут вернуться как спутники после отдельного UX-решения.

**Огород:** один начальный слот, два последующих можно купить; независимые грядки, разный состав семян, полив, пауза роста при дефиците воды, время сбора, автополивалка без автопосадки/автосбора. Демонстрационные культуры:
- Мандрагора: 90 секунд роста после начального полива, 2 секунды сбора, 2 единицы.
- Антарктическая кусака: 250 секунд роста, полив в начале и после 125 секунд накопленного роста, 5 секунд сбора, 3 единицы.
Цены и продолжительности **черновые**, подлежат системному балансу после полной цепочки.

**Алхимия:** шесть классов (Новичок → Грандмастер) и независимые шесть ступеней качества (Отвратительная → Мастерская); базовый раствор + обязательная основа + необязательная добавка. 4 реализованных рецепта (Healing, Огненный танец, Северный укус, Лунное эхо). Gold покупает семена и реагенты; Essence расходуется при запуске варки; готовое зелье появляется как отдельный предмет, Gold начисляется лишь при подтверждённой продаже. Редкость, префикс/суффикс и визуальные/эффектные поля есть; сами эффекты оборудования пока **заглушки**.

**Визуальная сцена:** расширенный остров 184 × 172, 48 предусмотренных деревьев, прежние станции и собственный R3 World Tree фон. P0 ради проверки стабильности фиксирует статические силуэты вместо анимированного переключения LOD; сервер добавляет невидимые коллайдеры для стволов/камней. Последний патч восстанавливает CloudOcean/CloudOcclusion/AtmosphericHaze из до-P0 R3; предыдущий патч с пустым небом **отменён**.

## 5. Запуск, фиксация результата и безопасность

```sh
git clone https://github.com/branch-danya-dev/magicpotiongacha.git
cd magicpotiongacha
git switch handoff/claude-code-v1-03
node --version
npm run tools
npm run handoff:verify
npm test
node scripts/build-alchemy-first.mjs --owner-user-id=<YOUR_ROBLOX_USER_ID>
node scripts/verify-handoff.mjs --built
```

**Только** `build/PotionTycoon-Alchemy-First-QA.rbxlx` — текущая изолированная сцена. `build/PotionTycoon.rbxlx` остаётся историческим результатом сборки `default.project.json`. Открой соответствующий файл в Studio через File → Open from File и Play (F5). При ошибке владельца сначала сверить `Workspace.AG76QAOwnerUserId` и `build/alchemy/build.json.owner`, не удалять механизм проверки.

`npm run tools` загружает зафиксированные Luau 0.745 и Rojo 7.7.1 с проверкой SHA-256. CI использует временный owner `-1`; он подходит для автоматики, но обычного пользователя в Roblox Studio не впускает. Авторские ID и API-гейтвеи не должны сохраняться в инструкциях/секретах проекта.

**Перед отчётом агента:** точный HEAD, изменения файлов, схемы данных, полный `npm test`, Windows/Ubuntu CI, `build/alchemy/build.json`, Studio F5 с видео/скриншотами если доступны, отдельные NOT RUN для телефонов/живой DataStore/2–8 клиентов/Robux. Состояние `CODE VERIFIED` не означает `OWNER ACCEPTED`.
